## 这是什么

**[剪灵 NimbleCut](https://nimblecut.com)** 官方维护的 AI 创作提示词合集，按 **图片 / 视频 / 短剧 / 分镜到视频** 四大场景拆分，共 **21,496** 条、**923** 个主题文件。

与零散 Prompt 片段不同，本库每条提示词均包含：

| 模块 | 作用 |
|:---|:---|
| **任务** | 明确生成目标（单图、连贯视频、短剧包、分镜图等） |
| **执行要素** | 主体、场景、动作、镜头、节奏等硬性约束 |
| **风格 / 光影** | 画面情绪、材质、构图与连续性要求 |
| **质量控制** | 稳定性、可读性、成片质感底线 |

打开任意 `.md` 文件 → 找到 **提示词** 小节 → 复制 `text` 代码块即可使用。  
`text` 块内**不含品牌信息**，不会污染你的生成 Prompt。  
想自己写 Prompt？请参阅 **[优秀 Prompt 要素与优化规范](./优秀Prompt要素.md)**。


### 单条提示词长什么样

每个条目由 **Markdown 元信息** + **可复制的 text 代码块** 两部分组成：

**① 元信息（浏览用，一般不用复制）**

```text
大领域：商业产品·透明运动鞋
细分类：商业产品·透明运动鞋/透明运动鞋/透明运动鞋冰块03/珊瑚色几何影棚…
```

**② 提示词正文（复制下面整个代码块到 AI 工具）**

```text
任务：生成高质量单张图像，直接输出画面结果。
主体：透明运动鞋，作为清晰主视觉，身份、材质和轮廓必须稳定。
场景：珊瑚色几何影棚，屏幕亮度成为主要光源，阴影中仍保留结构细节……
镜头构图：竖屏优先，中近景或全景按主体尺度选择……
风格光影：高端商业摄影，材质反射真实，背景干净……
质量控制：画面清晰自然，主体稳定，构图完整，材质可信……
```

`图片` · 高端商业摄影 · 材质反射 · 图生视频预留构图  
→ [`图片/商业产品·透明运动鞋.md`](./图片/商业产品·透明运动鞋.md)

```text
任务：生成高质量单张图像，直接输出画面结果。
主体：透明运动鞋，作为清晰主视觉，身份、材质和轮廓必须稳定。
场景：珊瑚色几何影棚，屏幕亮度成为主要光源，阴影中仍保留结构细节，前景、中景、背景有明确层次，环境道具服务主题。
动作/事件：透明运动鞋被放在冰块旁，水珠沿包装边缘滑落，摄影助理的手刚离开画面，随后空气中的粒子被吸向同一点，让观众一眼看懂正在发生的具体内容。
```

```text
质量控制：画面清晰自然，主体稳定，构图完整，材质可信，文字仅在必要处出现且准确可读。
```

### 电影场景 · 雨夜通勤者

`视频` · 8–12 秒 · 四镜头叙事 · 雨夜悬疑  
→ [`视频/电影场景·雨夜通勤者.md`](./视频/电影场景·雨夜通勤者.md)

```text
任务：生成 8-12 秒连贯视频，直接按镜头描述执行。
主题：雨夜通勤者在湿润沥青街口，远处红色信号灯反复闪烁，动线从前景引向主体中经历“雨夜通勤者在倒影中看见夜班保安逼近，立刻改变前进方向，随后空气中的粒子被吸向同一点”。
镜头 01：建立场景，缓慢推进到雨夜通勤者，交代空间、光线和关键道具，动作只做铺垫。
镜头 02：事件启动，雨夜通勤者在倒影中看见夜班保安逼近，立刻改变前进方向，随后空气中的粒子被吸向同一点，镜头跟随主体移动，保持运动方向清楚。
镜头 03：细节放大，切到潮湿信封或主体局部，展示材质、表情、机械结构、液体、火光或粒子变化。
镜头 04：结尾定格，夜班保安或环境反应进入画面，形成明确结果或悬念。
风格光影：电影级写实，浅景深，雨雾与环境光制造悬念，动作因果清楚；整体情绪为复古浪漫。
统一要求：每个镜头只做一个主要动作，相邻镜头保持角色身份、道具、位置、光线方向和特效因果一致。
```

### 竖屏短剧 · 冰原巨狼

`短剧` · 钩子 + 角色锁定 + 情绪峰值 + 结尾悬念  
→ [`短剧/奇幻大片·冰原巨狼.md`](./短剧/奇幻大片·冰原巨狼.md)

```text
任务：生成可直接用于 AI 短剧制作的提示词包。
剧名：《冰原巨狼蓝色冰裂08之夜》
类型与卖点：奇幻大片·冰原巨狼题材，围绕冰原巨狼在冰原巨兽脚印内遭遇“冰原巨狼触发蓝色冰裂，远景出现宏大尺度的能量变化，随后桌面上的小物件自己移动了一寸”展开，主打荒凉孤独和强画面钩子。
角色锁定：
1. 主角：冰原巨狼，目标是解决眼前事件或守住关键秘密。
2. 对手/阻力：巨兽，带来误会、竞争、危机或反转。
3. 关键道具：蓝色冰裂，必须贯穿开场、升级和结尾。
剧情节奏：
开场钩子：主角刚进入冰原巨兽脚印内，异常事件立刻发生。
冲突升级：巨兽逼近，主角发现蓝色冰裂与真相有关。
情绪峰值：蓝色冰裂被放大到最有戏剧张力的一刻。
结尾悬念：主角做出选择，但画面留下新的证据或未解释的变化。
镜头要求：竖屏短剧，镜头短而清楚，人物关系和动作因果必须可拍摄。
```

### 分镜到视频 · 四宫格工作流

`分镜到视频` · 2×2 分镜图 → 逐格图生视频 · 连续性约束  
→ [`分镜到视频/奇幻大片·冰原巨狼.md`](./分镜到视频/奇幻大片·冰原巨狼.md)

**Step 1 · 分镜图生成**

```text
任务：生成 4 格分镜图，画布布局为2x2 四宫格。
题材：奇幻大片·冰原巨狼。
角色/主体锁定：冰原巨狼为主视觉，巨兽作为关系对象或环境阻力，关键道具为蓝色冰裂。
分镜内容：
01. 建立场景：冰原巨兽脚印内，室内外色温明显分层，地面倒影暴露隐藏信息。
02. 主体动作：冰原巨狼触发蓝色冰裂，远景出现宏大尺度的能量变化。
03. 冲突升级：冰原巨狼与巨兽或蓝色冰裂发生关系变化，动作只推进一个重点。
04. 结尾悬念：保留蓝色冰裂作为悬念视觉点。
画面风格：奇幻史诗大片，宏大尺度，特效从具体道具或动作触发，情绪为荒凉孤独。
```

**Step 2 · 分镜生视频**

```text
任务：基于上方 4 格分镜图逐格生成视频，每格对应一个镜头，镜头数量严格保持一致。
镜头 01：使用分镜图第 1 格作为首帧，生成 2-3 秒视频；建立场景与空间层次。
镜头 02：使用分镜图第 2 格作为首帧，生成 2-3 秒视频；执行主要动作，特效或物理变化必须有起因。
镜头 03：使用分镜图第 3 格作为首帧，生成 2-3 秒视频；延续上一格位置关系。
镜头 04：使用分镜图第 4 格作为首帧，生成 2-3 秒视频；形成可停顿的结尾。
统一要求：相邻镜头保持主体身份、服装/材质、关键道具、场景方位、光线方向和特效连续性一致。
```
